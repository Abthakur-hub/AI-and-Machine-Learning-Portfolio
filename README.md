## Project Overview

This repository contains a collection of Artificial Intelligence, Machine Learning, Deep Learning, Reinforcement Learning, Computer Vision, and Retrieval-Augmented Generation (RAG) projects developed using Python and related frameworks. These projects demonstrate practical implementations of various AI techniques, model development, deployment, and real-world problem-solving.

---

# Projects Included

### 1. Adult Census Income Classification
- Machine Learning model for predicting whether an individual's annual income exceeds \$50K based on census data.

### 2. CIFAR-10 Image Classification using CNN
- Image classification using a Convolutional Neural Network (CNN) on the CIFAR-10 dataset.

### 3. Face Recognition using CNN (LFW Dataset)
- Face recognition system built using the Labeled Faces in the Wild (LFW) dataset.

### 4. Cancer Detection using MRI Images
- Brain tumor classification from MRI images using a CNN-based deep learning model.

### 5. CartPole Reinforcement Learning Agent
- Deep Q-Network (DQN) agent trained to balance a cart-pole system.

### 6. Lunar Lander Reinforcement Learning Agent
- Reinforcement learning agent trained to land a spacecraft safely.

### 7. Movie Recommendation System
- Content-based movie recommendation system using similarity measures.

### 8. End-to-End Machine Learning Deployment
- Complete ML workflow including preprocessing, model training, Flask API, Docker, and deployment.

### 9. RAG Chatbot
- Retrieval-Augmented Generation chatbot using Large Language Models (LLMs) and vector databases.
